번역어 연결과 추천 범위

한국어 번역어의 빨간 밑줄은 수록된 구절별 편집 연결 또는 사용자가 직접 저장한 연결입니다. 전체 성경의 완전한 단어 정렬 자료가 아닙니다. 연결이 없는 단어는 추측해 칠하지 않습니다. 원어 사용례에서는 동일한 어휘 식별자·기본형의 실제 단어를 강조합니다. 33개 목회 주제와 36개 시작 본문을 지원하며, 입력한 상황을 진단하거나 하나님의 뜻을 판정하지 않습니다.

가공과 절 번호

2026년 9월 29일 수집한 공개 자료를 검색·표시용 JSON으로 변환했습니다. 한국어·영어는 제공처의 VPL 본문을 사용하고, 원어는 기본형·형태 코드를 보존했습니다. 히브리어는 OSHB의 VerseMap을 참고해 대응 절을 연결하되 원래 절 번호를 함께 표시합니다. 부분 대응은 원문 절 전체를 보여 주며 단어별 번역 대응을 뜻하지 않습니다. 케레·케티브의 별도 읽기와 본문 비평 장치는 이 버전에 포함하지 않았습니다.

같은 어휘의 사용 구절은 주제별 관주가 아닙니다. 형태 정보와 기본형만으로 문맥의 의미를 확정하지 마세요. 매튜 헨리 간결 주석 영어 원문을 수록하고 주요 추천 본문에 한국어 편집 요약을 제공합니다. 상황 추천과 설교 틀은 준비된 자료와 사용자의 노트를 조합하는 방식이며 AI 답변이 아닙니다.

노트와 개인정보

상황 입력·설교 설계·제작 프롬프트 생성은 외부 API를 호출하지 않습니다. 주석의 한국어 전체 번역은 지원되는 데스크톱 브라우저의 기기 번역 기능을 사용하며 최초 언어 자료 다운로드가 필요할 수 있습니다. 미지원 환경에서는 영어 원문·기존 한국어 요약과 번역용 프롬프트를 제공합니다. 전체 한국어 번역이 미리 수록된 것은 아닙니다. 노트와 직접 연결한 번역 표현은 서버로 전송하지 않고 이 기기의 브라우저에 저장합니다. 같은 브라우저를 함께 쓰는 사람은 노트를 볼 수 있습니다. 다른 기기로 옮기려면 전체 백업 파일을 내려받고 복원하세요. 복원 시 기존 노트와 충돌하면 복원 창에서 처리 방식을 선택합니다.
